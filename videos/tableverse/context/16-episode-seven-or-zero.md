## Facts (official CCSS Mathematics PDF, https://corestandards.org/wp-content/uploads/2023/09/Math_Standards1.pdf,
sha256 2d28ded26c7394f55525550e32bb96786da2e9a3276ccca8873e80ebcdebab11, retrieved 2026-11-13, re-read 2026-11-17)
- 3.OA.A.1: "Interpret products of whole numbers, e.g., interpret 5 × 7 as the total number of objects in 5 groups of
  7 objects each." → 7 × 1 = total in 7 groups of 1 = 7; 7 × 0 = total in 7 groups of 0 = 0.
- Glossary, Table 3 (properties of operations): "Multiplicative identity property of 1: a × 1 = 1 × a = a." → 7 × 1 = 7.
- 3.OA.D.9: identify patterns in the multiplication table and explain them (the ×0 row and column are all 0).
- Note: CCSS Table 3 does not list a named "zero property"; 7 × 0 = 0 is stated here from the equal-groups meaning
  (seven groups that each hold nothing hold nothing), i.e. 0 + 0 + 0 + 0 + 0 + 0 + 0 = 0, true for any whole number of
  groups. The narration says "any number" in the whole-number sense used throughout the app's tables.
- Measured facts = arithmetic. Counted objects on screen: exactly 7 boxes; 1 cookie in each (7) until the mouse eats
  them; then 0 in each. Mouse, boxes, bakery and baker are illustrative. No app capability claimed.
