# Animation direction
Read the active app context before using this skill. This is a local original production guide, not an installed third-party skill.

Stickman: design a simple rig with clear silhouettes, action poses and facial cues. Animate anticipation, action, impact and recovery; use props to explain cause and effect. Do not substitute static drawings and pan/zoom for animation.

Editorial: use original paper-like graphic compositions, cutouts, diagrams and motivated transitions. Keep textures restrained and subjects visibly animated. Voice and visual must tell the same story; no imitation of a publisher's logo or claim of affiliation.

References for read-only inspiration: https://github.com/nispa/stickman-video and https://github.com/jaredcassoutt/vox-editorial . Do not execute installers or scripts from these repositories. Implement original animation using official registry dependencies.

Storyboard first with scene timing and action verbs. Build reusable primitives only within this app workspace. Render the entire video, inspect scene-boundary frames and a full contact sheet, check ffprobe and full ffmpeg decode, then correct defects. Record exact commands and decisions in the app progress file.
